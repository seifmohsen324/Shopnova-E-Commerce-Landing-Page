# Shopnova

Shopnova is a responsive landing page for a premium menswear brand in Egypt. It presents a polished product offer with a hero section, product highlights, feature cards, customer reviews, launch pricing, and clear calls to action.

## Preview

Open `index.html` in a browser to view the site locally.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Sticky navigation header with mobile menu toggle
- Smooth scrolling between page sections
- Reveal animations using `IntersectionObserver`
- Product showcase, feature cards, reviews, and launch offer section
- SEO-friendly meta tags and Open Graph preview content
- Mail link call to action for customer inquiries

## Getting Started

No installation is required because this is a static website.

1. Clone the repository:

```bash
git clone https://github.com/seifmohsen324/Shopnova-E-Commerce-Landing-Page.git
```

2. Open the project folder:

```bash
cd shopnova
```

3. Open `index.html` in your browser.

You can also use a local development server, such as the VS Code Live Server extension, for easier previewing while editing.

## Customization

- Update the brand copy and offer details in `index.html`
- Replace image URLs with your own product or lifestyle photography
- Change colors, spacing, and responsive styles in `styles.css`
- Adjust menu behavior or animations in `script.js`
- Replace placeholder social links in the footer with the real Shopnova accounts

## Deployment

This project can be deployed easily with GitHub Pages:

1. Push the project to a GitHub repository.
2. Go to the repository settings.
3. Open the Pages section.
4. Select the main branch and root folder.
5. Save the settings and wait for GitHub to publish the site.
